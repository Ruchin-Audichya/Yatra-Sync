# Presenting Yatra Sync

Open http://127.0.0.1:3002/demo/present while the local server is running. The presentation is a standalone sandbox; it never modifies the database. Use arrow keys to change chapters, N for presenter notes, and the fullscreen control for a clean presentation.

1. **The problem, 20 seconds.** At the end of a workday, several people book separate cabs in the same direction. The missing step is finding each other before booking.
2. **The match, 30 seconds.** Click “Find their match.” Explain the computed limits, not an AI promise. These fixed synthetic Jaipur journeys run through the real matching engine.
3. **The split, 25 seconds.** Change the fare and show that exact paise shares reconcile, even with different drop-offs.
4. **The agreement, 25 seconds.** Simulate each approval. Explain that the working app requires separate authenticated people to accept the current terms.
5. **The recovery, 30 seconds.** Simulate Kabir leaving. Suggest a replacement. Return to consent to show that the changed group needs fresh approvals.
6. **The evidence, 25 seconds.** Run the benchmark. Compare matching outcomes on the same synthetic inputs; these are not real-world adoption or savings figures.
7. **The product, 25 seconds.** Enter the working app. Show the office/station/airport composer and the quote comparison. A high quote does not automatically mean sharing wins.

The on-screen timer is a presentation aid, not a countdown that commits a ride. Replay resets presentation state only. Fixed scenarios remain repeatable even when local trip records expire.
